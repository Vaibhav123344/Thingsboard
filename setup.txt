# Industrial AI Observer - Full Application Setup & Run Guide

This document outlines the complete steps to set up and run the entire pipeline, including the ThingsBoard backend, the Node.js Express tools gateway, the LiveKit server, the local Faster-Whisper STT microservice, and the Python Voice Agent pipeline.

---

## Prerequisites
- **Node.js** (v18+ recommended)
- **Python** (v3.10+ recommended) with `uv` package manager installed
- **Docker & Docker Compose** (for ThingsBoard core services)
- **Ollama** installed with your target model (e.g., `gpt-oss:latest` or `llama3`)

---

## 1. Start the ThingsBoard Backend (Docker)
ThingsBoard, PostgreSQL, and Redis run via Docker Compose.
1. Open a terminal in the project root (`d:\Vaibhav\Projects\Thingsboard`).
2. Run the compose file:
   ```cmd
   docker-compose up -d
   ```
3. Wait a minute or two for the services to fully initialize.

---

## 2. Start the Express Tools Gateway & Simulator
This Node.js server exposes the ThingsBoard REST API and MQTT simulator to the AI agent on port `9005`.
1. Open a terminal in the project root (`d:\Vaibhav\Projects\Thingsboard`).
2. Install dependencies (first time only):
   ```cmd
   npm install
   ```
3. Start the server:
   ```cmd
   npm run dev:agent
   ```
   *You should see "Unified Server ... is online on Port 9005."*

---

## 3. Start the Local LLM (Ollama)
Ensure your Ollama server is running and accessible (defined in `voice_agent/.env.local`).
1. Start Ollama:
   ```cmd
   ollama serve
   ```
   *(Or just make sure the background process is running).*
2. Ensure you have the model pulled:
   ```cmd
   ollama run gpt-oss:latest
   ```
   *(Replace with the actual model name you are using).*

---

## 4. Start the Local STT Microservice (Faster-Whisper)
The Speech-to-Text service runs as a separate FastAPI server on port `8765`.
1. Open a new terminal and navigate to the STT directory:
   ```cmd
   cd d:\Vaibhav\Projects\Thingsboard\voice_agent\stt
   ```
2. Start the FastAPI server using `uv`:
   ```cmd
   uv run uvicorn stt_service:app --host 0.0.0.0 --port 8765 --workers 1
   ```
   *Wait for the "Faster-Whisper model ready" log message.*

---

## 5. Start the LiveKit Server
The LiveKit server handles WebRTC audio routing.
1. Open a new terminal and navigate to the voice agent directory:
   ```cmd
   cd d:\Vaibhav\Projects\Thingsboard\voice_agent
   ```
2. Run the LiveKit development server:
   ```cmd
   livekit-server.exe --dev
   ```
   *Note: This will print the `LIVEKIT_API_KEY` and `LIVEKIT_API_SECRET` to the console. Ensure these match what is in your `.env.local`.*

---

## 6. Start the Main Voice Agent Pipeline
This orchestrates the STT, LLM, and the in-memory Kokoro TTS plugin, connecting to LiveKit and the Express tools gateway.
1. Open a new terminal and navigate to the voice agent directory:
   ```cmd
   cd d:\Vaibhav\Projects\Thingsboard\voice_agent
   ```
2. Check your `.env.local` file to ensure URLs are correct (LiveKit, Ollama, and Tools).
3. Start the agent:
   ```cmd
   uv run python src/agent.py dev
   ```
   *(Or use `uv run python src/agent.py start` if you don't want the dev watcher).*

---

## Summary of Ports
- **8080** / **9090** / etc.: ThingsBoard (Docker)
- **9005**: Express Tools Server (Node.js)
- **11434**: Ollama LLM
- **8765**: Faster-Whisper STT Microservice (Python/FastAPI)
- **7880**: LiveKit Server
- **Agent**: Connects outbound to LiveKit, STT, and Tools gateway.
